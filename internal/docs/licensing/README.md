# Licensing Terminology and Decisions

This directory records the terminology and decisions behind the
`react-on-rails-rsc` 19.2.1 commercial license boundary and earlier React on
Rails Pro terms. The React 19.3 releases retain their shipped terms. The next
React runtime minor line can adopt The ShakaStack License, version 1.0,
applied to React on Rails Pro, beginning with package version `19.4.0`.
The license source is maintained in `shakacode/commercial-licensing`.
